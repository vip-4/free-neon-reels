What Neon Reels is — and what it deliberately is not

Key specifications, so you can judge the game before you spend a single spin on it.

Neon Reels is a single-player slot machine simulation. Each spin draws nine symbols from a weighted pool and evaluates five paylines plus a diamond scatter. The design goal was a complete slot game in under 30 KB of hand-written CSS and JavaScript: no framework, no sprite sheet, no web font, no third-party script.

It is not a gambling product. There is no deposit, no withdrawal, no cash value and no way to convert credits into anything. It is a demonstration of how a casino-style game loop, a provably weighted random number generator and a fully accessible interface can fit in a static page — useful as a teaching reference, a portfolio piece, or a five-minute distraction.

How to play in four steps

There is no tutorial, no timer and no penalty for stopping. The full rules fit in four lines.

  1. Set your bet. Use the − and + buttons to choose 5, 10, 25, 50 or 100 credits per spin. Your bet is split evenly across the five paylines.
  2. Spin. Press the Spin button or the Space bar. Each reel stops left to right; the outcome is already fixed the moment the spin starts.
  3. Match three symbols on a payline. Any of the five lines — top, middle, bottom, and both diagonals — pays when all three of its symbols match. Payouts are the symbol multiplier times your per-line bet.
  4. Collect diamonds. Three or more diamonds anywhere on the grid pay a scatter bonus of 2× to 50× your total bet, independent of the paylines.

How the 91.4% return-to-player is calculated

No hidden tuning: the number follows directly from the weights and multipliers in the paytable above.

Each symbol has a fixed probability of weight ÷ 100. Because the three reels are independent, the chance of three identical symbols on one payline is that probability cubed. Multiplying by the payout and summing across all six symbols gives the expected return of a single payline: 17.634%.

A spin always plays five paylines, so line wins return 5 × 17.634% = 88.17% of the stake. The diamond scatter adds a further 3.19% (2× on 1.25% of spins, 5× on 0.12%, and progressively rarer higher tiers). The two components sum to 91.36%, rounded to 91.4%.

Read this before you interpret RTP. 91.4% is a long-run average across millions of spins. It does not mean you will get 91.4% of your credits back in any one session, and it is not a prediction about your next spin. Individual sessions routinely swing far above or below it — that variance is the entire point of the game.

Performance, accessibility and privacy by construction

Constraints chosen up front, not retrofitted. These are the measurable outcomes.

  • One request per asset

    A single HTML document, one stylesheet and one script. No framework, no polyfill, no CDN, no web font. The whole page is 62 KB uncompressed and 17.5 KB gzipped.

  • Text-first rendering

    The largest contentful paint element is the headline, so the page paints before any script runs. The game script is deferred and non-blocking.

  • No layout shift

    Reel and HUD dimensions are reserved in CSS with fixed cell heights, so the machine does not resize when symbols render. Cumulative layout shift stays at 0.

  • Keyboard complete

    Every action is reachable by Tab, Space spins, focus is never hidden, and a skip link jumps straight to the game.

  • Screen-reader narrated

    Results stream through an aria-live="polite" region as plain sentences — line, symbol, amount — rather than as bare numbers.

  • Motion is optional

    prefers-reduced-motion removes the reel animation and resolves each spin instantly, with no loss of information.

  • Contrast checked

    Body and secondary text meet WCAG AA against the dark surface; state is never conveyed by colour alone — wins also change the label text.

  • Zero telemetry

    No cookies, no analytics, no fingerprinting. Your balance lives in your own browser's local storage and never leaves the device.

Provenance: how this build was sourced and screened

The brief was to ship a lightweight static casino game. Candidate references were screened against five public sources before any code was written; the outcome is documented here so the decision is auditable.

  • itch.io — open-source tag Used to survey small browser-native slot and card games and their asset budgets. The recurring finding: most entries ship a 1–3 MB bundle dominated by audio and sprite atlases, which contradicts a lightweight static target.
  • GitHub Trending (daily) Used to confirm current practice for dependency-free canvas and DOM games. Trending projects skew heavily toward engine-based builds, so the useful signal was the small minority of single-file implementations.
  • Ludum Dare game jam archive The LudumDare GitHub organisation and jam entries were reviewed for 48-hour scope discipline: one mechanic, one screen, immediate play. That constraint shaped the decision to ship a single machine instead of a lobby.
  • Simple Game Tutorials simplegametutorials.github.io provided the reference pattern for a plain-HTML game loop with no build step — the same structure used here, adapted to a weighted-RNG slot rather than a grid puzzler.
  • itch.io API Consulted for catalogue metadata (tags, licence fields, file size) as a screening filter. No third-party code, art or audio from any of these sources is included in this build.

Result. Rather than repackage an existing jam entry with unclear licensing, Neon Reels is an original implementation: hand-written markup, CSS and JavaScript, MIT licensed, with no third-party assets. That keeps the licence clean, the payload small, and the whole game readable in a single sitting.

Frequently asked questions

Short, direct answers to the questions this page most often receives.

Is Neon Reels free to play?

Yes. There is no purchase, subscription, in-app currency or advertising gate. Every credit is virtual and has no monetary value, and the game can never be used to win or lose real money.

Do I need to download or install anything?

No. The game is a single static web page built with plain HTML, CSS and JavaScript. It needs no plug-in, no app-store install and no account, and it keeps working offline once your browser has cached the page.

What is the return-to-player of Neon Reels?

Approximately 91.4%. Line wins contribute 88.17% and the diamond scatter contributes 3.19%. RTP is a long-run average over millions of spins — not a promise about any single session.

Does it work on mobile phones and offline?

Yes. The layout is responsive from 320 pixels wide upwards with touch-sized controls, and because the page has no external dependencies it also runs with no network connection after the first visit.

Is the game accessible with a keyboard or screen reader?

Yes. Every control is a native button reachable by Tab, Space spins the reels, focus outlines are always visible, and results are announced through an ARIA live region. The prefers-reduced-motion setting removes the reel animation entirely.

Where is my credit balance stored?

In your own browser's local storage — nothing is uploaded and no account is created. Clearing site data, or pressing Reset session, returns you to the 1,000-credit starting balance.
